# Baguettes

## About This Mod
This mod adds a Baguette item to Minecraft. Crafted from 3 pieces of bread, the Baguette fully replenishes both hunger and saturation bars, offering a simple and balanced food upgrade.

## Features
- Adds a Baguette item to the game
- Restores 15 hunger and 15 saturation
- Crafting recipe: 3 Bread, placed diagonally in the crafting grid
